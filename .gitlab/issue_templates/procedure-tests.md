## Procédure de tests

--

1. Chaque membre de l'équipe est taggué sur la ou les cartes à tester ;
2. Chaque membre de l'équipe test avec son navigateur et son rôle ;
3. Si des problèmes sont identifiés, je fais une carte par retour dans la colonne à tester. J'utilise le template "retour_tests" pour consigner mes retours ;
4. Les cartes sont priorisées ensuite dans les colonnes `tests-à corriger` & `tests-améliorations` ;
5. Une fois les tests terminés, l'indiquer en commentaires dans cette carte ;
6. Une fois les corrections apportées, tagguer Clara et/ou personne à l'origine de la carte pour retester
7. Une fois derniers tests effectués, la carte peut passer dans la colonne `Ok pour MEP`
